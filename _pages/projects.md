## Open-Source Software

### Benchmarking Framework for Polynomial-Based Universal Hash Functions

Together with Jan Gilcher, I develop and maintain a modular benchmarking framework for implementing and evaluating polynomial-based universal hash functions.

The framework includes implementations of Poly1163, which achieves up to a 40% speedup over Poly1305 while targeting the same security level. Moreover, the new design MHP-NMH+ achieves up to a 25% speedup over other evaluated state-of-the-art constructions.

[GitHub repository](https://github.com/jangilcher/polynomial_hashing_framework)
